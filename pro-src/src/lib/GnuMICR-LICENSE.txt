WHITE-LABEL / EMBEDDING NOTE
----------------------------
GnuMICR is GPL-2.0 (copyleft). Author Eric Sandeen's README additionally states a
WISH (not a license term) that the font not be built into proprietary software,
but instead be distributed AS A SEPARATE FILE alongside the application with the
license and source intact.

For a proprietary / white-labeled product, the clean options are:
  1. Ship GnuMICR.ttf as a separate asset file (not compiled into the app
     binary/bundle), with this LICENSE and the font source available; OR
  2. Use a permissively-licensed (OFL / MIT / Apache / public-domain) E-13B font
     if the font must be embedded into a proprietary bundle.

Embedding a subset of the font into individual generated check PDFs (as this
generator does) is normal document font embedding; the bundling of the font into
the application distribution is the part to review for GPL compliance.

Accuracy note: this TTF was converted from the Type 1 source by a third party;
the author's hand-tuned PostScript Type 1 version is the dimensionally accurate
one. For laser check printing this TTF is fine; if bank-reader reject rates
matter, validate printed output with a MICR reader.
